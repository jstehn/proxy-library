# Code of conduct

Proxy Library is a small, friendly project for playing Magic with other people. Please keep
the project that way.

## What we expect

- Be kind and patient. Assume people are doing their best.
- Keep feedback about the code or the idea, not the person.
- Harassment, insults and discrimination (for example about race, gender, sexuality, religion,
  disability or nationality) are not welcome in issues, pull requests or discussions.

## Our intent for the software

I don't want this project used to hurt people or to spread hatred. This is a statement of
intent, not a licence condition: the code is licensed under [0BSD](LICENSE), which allows any
use, and this document does not change that. It tells you what I hope for, and what I will not
help with. I may close issues and pull requests, or block people, who use the project for
hateful purposes.

## Reporting

If someone breaks this code of conduct, open an issue, or contact the maintainer, Jack Stehn,
through the contact details on his GitHub profile. Reports are handled privately where
possible. The maintainer decides what happens next.
