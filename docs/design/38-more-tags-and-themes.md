## 1. Purpose & scope

While building Commander decks from owned cards, several common archetypes and multiplayer plans could not be expressed as stored `theme_tags` or `otag:` / `theme:` searches because `THEMES` in `src/shared/card-search/tags.ts` only covered ten initial themes (`counters`, `tokens`, `sacrifice`, `graveyard`, `artifacts`, `enchantments`, `lifegain`, `spells`, `landfall`, `equipment`).

Furthermore, all token cards were lumped into a single `tokens` theme, so a Treasure commander and a Goblin creature-token card treated each other as equally on-theme.

This phase expands `THEMES` from 10 to **32 themes** using an **overlapping umbrella + sub-theme hierarchy**:

- **Token hierarchy:** `tokens` (umbrella) overlaps with `creature-tokens` and `artifact-tokens` (umbrella for non-creature/artifact tokens), which in turn overlaps with `treasures`, `food`, and `clues`.
- **Politics & multiplayer hierarchy:** `politics` (umbrella) overlaps with `goad`, `voting`, `group-hug`, and `monarch`, alongside `each-opponent` (multiplayer scaling / group-slug / drain).
- **Major Commander archetypes:** `blink` (flicker / ETB reuse), `wheels` (discard & wheel payoffs), `clones` (copy spells & permanents), `theft` (gain control / play opponents' cards), `planeswalkers` (Superfriends), `legends` (Legendary / historic matters), `exile` (cast from exile / impulse draw / cascade / discover / foretell / plot / suspend), `extra-combat` (extra combat phases & attack-trigger doublers), `stax` (resource denial, hatebears, tax & rule-setting), `poison` (infect, toxic, poison counters), and `vehicles` (Vehicles, Mounts, crew & saddle).

Because `deckFit` (`src/modules/decks/domain/suggest.ts`) sums points across shared themes, overlapping umbrella + sub-theme tags automatically act as a hierarchical scorer:

- A Treasure card shares **3 themes** (`tokens`, `artifact-tokens`, `treasures` = 9 points) with a Treasure commander, whereas an unrelated creature-token card shares only `tokens` (3 points).
- A Voting card shares **2 themes** (`politics`, `voting` = 6 points) with a Voting commander, while general political cards still match `politics` (3 points).

## 3. Search aliases (`otag:`, `function:`, `theme:`) in `src/shared/card-search/parse.ts`

1. **Tagger aliases (`TAGGER_ALIASES`, task `#87`):**
   Every `Tag` and `Theme` (plus common Scryfall Tagger synonyms like `treasure`, `creature-token`, `artifact-token`, `clue`, `investigate`, `food`, `political`, `pillowfort`, `forced-combat`, `vote`, `council`, `hug`, `grouphug`, `initiative`, `dungeon`, `group-slug`, `groupslug`, `flicker`, `blink`, `wheel`, `discard`, `clone`, `copy`, `steal`, `theft`, `superfriends`, `spellslinger`, `voltron`, `enchantress`, `aristocrats`) maps to `{ field: "tag" | "theme", value }` in `TAGGER_ALIASES`.
2. **Theme value normalization in `theme:`:**
   When a user writes `theme:<alias>` (e.g., `theme:treasure`, `theme:flicker`, `theme:grouphug`, `theme:superfriends`, `theme:wheel`, `theme:clone`), `parse.ts` resolves it via `themeAlias(value)` so both canonical theme names and natural synonyms work in `theme:` as well as `otag:` / `function:`.
