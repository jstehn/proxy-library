# Decisions to review

Phases 6–11 were built in one unattended overnight run (2026-09-27 → 28). Design docs were
**self-approved** so work could continue. Everything decided without you is listed here, so you can
review it in one place. Anything can still be changed.

## Start here

Everything on the roadmap is built (Phases 0–11), with a lesson per phase. To see it all:

1. `direnv reload`, `pnpm install`, then `pnpm dev:all` (database, migrations, app and worker).
2. Things to try: open the repaired Reality Fracture precon in **Inventory** (it becomes a deck in
   **Decks**), buy a Secrets of Strixhaven precon, **Collection** sections, the deck builder's
   type-ahead, a trade between two accounts, **Activity** on the home page, the export links, and
   the phone layout.
3. Deploying: [deploy.md](deploy.md).
4. Then read the tables below and tell me what to change. The **Good alternative** column shows
   where there's a real choice to make.

gone to bed and asked me to decide; everything below can change.

| Decision                                                                                                                                                        | Why                                                                                                                                                                | Where to change it                                                                                  | Good alternative                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| **Each printing's role tags and themes are stored, worked out by a new sync step** (the tag pass), with a version number; `pnpm worker tag-cards` runs it alone | A rules-text search over the real catalog took 0.6 s; stored arrays with GIN indexes make each suggestion query 100–600 ms. Tagging all 76 000 printings took 17 s | `tagPass` in `catalog/application/sync.ts`; `CARD_FEATURES_VERSION` in `shared/card-search/tags.ts` | Compute per request (simpler, slower)                   |
| **Your dev database was migrated and tagged** (`pnpm db:migrate`, `pnpm worker tag-cards`) to measure the queries                                               | They need the new columns; the next `pnpm dev:all` would have done the migration anyway                                                                            | —                                                                                                   | —                                                       |
| **Ten themes**: +1/+1 counters, tokens, sacrifice, graveyard, artifacts, enchantments, lifegain, instants and sorceries, landfall, Equipment and Auras          | The common Commander archetypes that rules text shows reliably                                                                                                     | `THEME_RULES` in `tags.ts`                                                                          | Add more (flying, attacking, mill as its own)           |
| **A theme counts for a deck if its commander leads it, or 4+ cards and 10% of the spells fit it**                                                               | Without a commander (60-card decks) the deck itself has to show the theme                                                                                          | `THEME_MINIMUM`, `THEME_SHARE` in `decks/domain/suggest.ts`                                         | —                                                       |
| **A tribe: a commander's own type that its text names, or a type a third of the creatures share (5+)**. Class types (Soldier, Wizard…) count too                | Simple; some decks do build around Wizards                                                                                                                         | `deckProfile` in `suggest.ts`                                                                       | Leave class types out (lesson 20, exercise 4)           |
| **Weights: theme 3, tribe 3, short role 2, commander keyword 1; strength (rarity and price) only breaks ties**                                                  | Strength alone would suggest the priciest cards everywhere                                                                                                         | `WEIGHTS` in `suggest.ts`                                                                           | —                                                       |
| **Strength leans on price**, so expensive cards win ties                                                                                                        | Price is the only signal of power we have                                                                                                                          | `strength` in `suggest.ts`                                                                          | Prefer cheaper cards at a tie                           |
| **Each role's list ignores the deck's other gaps**                                                                                                              | Otherwise the same do-everything cards topped every role (seen on the real catalog)                                                                                | `scoreForRole`                                                                                      | —                                                       |
| **Non-Commander decks only get suggestions in the deck's colors** (any color if it has none yet)                                                                | A mono-red deck rarely wants a green card                                                                                                                          | `suggestionContext` in `decks/queries/suggestions.ts`                                               | Let the color buttons choose                            |
| **12 per pool for the deck, 6 per pool per role and for "cards like this"; 400 candidates per pool before scoring**                                             | Enough to choose from without a long scroll; the cut keeps queries fast                                                                                            | `deckSuggestions`, `CANDIDATE_LIMIT`                                                                | —                                                       |
| **Store suggestions are cards you don't own in any printing**, at the cheapest printing and finish for sale                                                     | The owned list already shows what you have                                                                                                                         | `storeCandidates`                                                                                   | Also suggest a cheaper printing of a card you own       |
| **Budget lists: points per dollar, prices under $1 counted as $1, at most 15 cards, one copy each, at most $1,000**                                             | Stops 10¢ filler crowding out good cards; one copy suits Commander                                                                                                 | `budgetPicks`, `BUDGET_LIST_MAXIMUM`, `BUDGET_MAXIMUM_CENTS`                                        | Two copies in 60-card decks                             |
| **Suggestions are additions only**; nothing suggests a card to cut                                                                                              | Cutting needs a judgment of card strength we don't have                                                                                                            | —                                                                                                   | A "weakest cards" list from role overlap (future-ideas) |
| **"Buy these" opens Buy a list with the list filled in** (`/singles/list?list=…`); it doesn't add the cards to the deck                                         | The existing flow checks prices and buys safely; the deck stays yours to change                                                                                    | `src/app/singles/list/page.tsx`                                                                     | Add them to the deck too, as short                      |
| **"Cards like this" loads when asked** (a link in the selected-card panel), not on every selection                                                              | Arrow keys move the selection quickly; a query each time would be wasteful                                                                                         | `selected-card.tsx`                                                                                 | Load automatically after a pause                        |
| **Keyboard: S opens or closes Suggestions**                                                                                                                     | Matches H for the test hand                                                                                                                                        | `deck-builder.tsx`                                                                                  | —                                                       |
| **The suggestions follow the deck**: they reload 0.6 s after the deck changes while the panel is open                                                           | A suggestion you've just added should disappear                                                                                                                    | `suggestions.tsx`                                                                                   | Reload only on a button                                 |
