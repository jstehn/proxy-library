# Glossary

Plain-language definitions of the terms used in the lessons and docs, with a Python comparison
where one exists. Lessons link here the first time they use a term.

| Term                                    | Meaning                                                                                                                                                                       | Python comparison                                                             |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| **`FILTER` (SQL)**                      | Limits one aggregate to certain rows: `sum(amount) filter (where kind = 'grant')`. Several totals in one query.                                                               | pandas `df[df.kind == "grant"].amount.sum()` per column                       |
| **`Pick<T, K>`**                        | A type made from only some properties of another: `Pick<Invite, "usedAt" \| "expiresAt">`.                                                                                    | a smaller `TypedDict` with some of the fields                                 |
| **`Record<K, V>`**                      | An object type with exactly the keys `K`, each holding a `V`. `Record<LedgerKind, "in" \| "out">` must list every kind.                                                       | `dict[LedgerKind, str]`, but every key is required                            |
| **Access token**                        | A password-like string that lets one program use another's service. One found embedded in someone's web page is their key, not an invitation to use it.                       | an API key in an `Authorization` header                                       |
| **Adapter**                             | A concrete implementation of a port. `systemClock()` is an adapter for the `Clock` port.                                                                                      | a class that satisfies a `Protocol`                                           |
| **Advisory lock**                       | A Postgres lock on a made-up number instead of a table row, held until the transaction ends. We use one so account changes happen one at a time.                              | `threading.Lock`, but shared by every server process via the database         |
| **Allow-list**                          | A list of what's accepted, with everything else refused. Safer than a deny-list, which tries to name everything forbidden and always misses something.                        | `re.fullmatch` against the only allowed pattern                               |
| **Anti-corruption layer (ACL)**         | The code at the edge that translates another system's data into our own types, so its shapes and quirks never spread into the app.                                            | a translation layer / adapter                                                 |
| **Anti-join**                           | Finding rows in one table with **no** match in another (`where not exists (…)`). Used to reconcile two ledgers.                                                               | a left merge with `indicator=True`, keeping `left_only`                       |
| **Append-only**                         | Data that is only ever added to, never changed or deleted. Mistakes are fixed by adding a new record.                                                                         | writing to a log file in "a" mode                                             |
| **Assertion / `as` cast**               | Telling the compiler "trust me, this is type X" without checking. Avoided in this project.                                                                                    | `typing.cast`                                                                 |
| **Async / `await`**                     | A function marked `async` returns a Promise. `await` pauses until the Promise has its value.                                                                                  | `async def` / `await`                                                         |
| **Async generator (`async function*`)** | A function that `yield`s values one at a time as they become available. Consumed with `for await`.                                                                            | an `async def` generator (`async for`)                                        |
| **Authentication**                      | Checking _who_ someone is (username + password).                                                                                                                              | Django's `authenticate()`                                                     |
| **Authorization**                       | Checking _what_ someone may do (e.g. only admins create invites).                                                                                                             | permission checks / `@permission_required`                                    |
| **Basis point**                         | One hundredth of a percent: 10000 basis points = 100%, 5000 = 50%. Lets percentages be whole numbers.                                                                         | —                                                                             |
| **Bleed**                               | Extra image printed around a card beyond where it will be cut, so a slightly-off cut still shows no white edge. Proxy PDFs can add 1/8 inch.                                  | —                                                                             |
| **Branded type**                        | A type like `Cents` that is a plain `number` at runtime but can't be mixed up with other numbers at compile time.                                                             | `NewType("Cents", int)`                                                       |
| **Bundle (JavaScript)**                 | The JavaScript files a browser downloads for a page: every module a client component imports, and everything those import. Server-only code must stay out of it.              | —                                                                             |
| **CHECK constraint**                    | A rule in a table's definition that the database enforces on every row, such as `quantity > 0`. It protects the data from any code that writes to it.                         | a Pydantic validator, enforced by the database                                |
| **Client Component**                    | A React component that also runs in the browser, so it can respond to clicks and typing. Marked with `"use client"` at the top of the file.                                   | — (JavaScript in the page)                                                    |
| **Client-safe module API**              | A module's second entry point (`client.ts`) that re-exports only pure code, so browser code can use it without pulling in the database (ADR 0016).                            | a helpers module that never imports `psycopg`                                 |
| **Closure**                             | An inner function that remembers the variables of the function that created it, even after that outer function has returned.                                                  | an inner `def` using the outer function's variables (`nonlocal`)              |
| **Commit / rollback**                   | Ending a transaction by keeping all its changes (commit) or undoing all of them (rollback).                                                                                   | `conn.commit()` / `conn.rollback()`                                           |
| **Companion object**                    | A value with the same name as a type that holds its helper functions, such as `Cents.of(...)` and `Cents.add(...)`.                                                           | a class used only for its static methods                                      |
| **Comparator**                          | A function of two items that `sort` uses: negative if the first comes first, positive if the second does, 0 for a tie.                                                        | the old `cmp=` functions; today a `key=` returning a tuple                    |
| **Compensating action**                 | Undoing a step that already happened, because it couldn't be part of the transaction. Here: deleting credentials if registration fails later.                                 | a manual `rollback` for an outside system                                     |
| **Composite (pattern)**                 | Handling a tree and its single nodes the same way: one function handles every kind of node and calls itself for the parts (products containing products).                     | a recursive function over nested lists or dicts                               |
| **Composition root**                    | The one place in the program where real implementations (database, clock, …) are created and handed to the code that needs them. Here: `src/server/core.ts`.                  | the `main()` that builds your objects                                         |
| **Const assertion (`as const`)**        | Tells TypeScript to keep a literal's exact values and make it read-only: `["a", "b"] as const` has type `readonly ["a", "b"]`, not `string[]`.                                | `Final` plus `Literal[...]` types                                             |
| **Contract test**                       | One test suite that every implementation of a port must pass, such as both the in-memory and Postgres repositories.                                                           | a shared pytest test class, subclassed per implementation                     |
| **Cookie**                              | A small value the browser stores and sends back with every request to the same site. Ours holds the session token.                                                            | `request.cookies` in Flask                                                    |
| **Corner marks (crop marks)**           | Short lines at each corner of a printed card, outside it, showing where to cut.                                                                                               | —                                                                             |
| **Correlated subquery**                 | A small `select` inside a query that refers to the outer row, run once per row ("for each card, its newest price").                                                           | a per-row lookup in `df.apply`                                                |
| **CTE (`WITH` query)**                  | A named sub-query at the top of a SQL statement, used by the rest of it like a temporary table.                                                                               | assigning an intermediate DataFrame to a variable                             |
| **De Morgan's law**                     | `!a && !b` means the same as `!(a \|\| b)`: "neither" is "not either". Useful for rewriting conditions so they read clearly.                                                  | `not a and not b == (not (a or b))`                                           |
| **Deadlock**                            | Two transactions each holding a lock the other needs, so neither can continue. Postgres detects it and aborts one. Prevented by always locking in the same order.             | two threads each holding one of two `Lock`s                                   |
| **Debounce**                            | Waiting until something stops happening for a moment (typing pauses) before acting, so one action runs instead of one per keystroke.                                          | resetting a `threading.Timer` on every event                                  |
| **Dependency**                          | Something a piece of code needs from outside to do its job: a clock, a database, another service.                                                                             | an object you'd pass to `__init__`                                            |
| **Dependency injection (DI)**           | Handing code its dependencies from outside instead of letting it create or import them itself. It makes swapping in fakes for tests easy.                                     | passing objects into `__init__` rather than creating them inside              |
| **Derived state**                       | A value computed from other state each render instead of stored separately, so it can't fall out of step ("loading" = results are for other filters).                         | a `@property` instead of an attribute you must remember to update             |
| **Discriminated union**                 | A union of object types that share a literal field (like `ok: true` / `ok: false` or `kind: "…"`), which the compiler uses to tell the cases apart.                           | `Union` of `TypedDict`s with a `Literal` tag field                            |
| **Docker image / container**            | An image is a packaged filesystem plus a command; a container is a running copy of it. Built in layers, one per Dockerfile instruction.                                       | a frozen virtualenv plus the OS files it needs, runnable anywhere             |
| **Domain**                              | The part of the code that expresses the app's rules (allowances, pack odds, ownership), with no database or web code in it.                                                   | pure "business logic" modules                                                 |
| **Duplex printing**                     | Printing on both sides of a sheet. Turning the sheet over swaps left and right, so backs go in mirrored columns.                                                              | —                                                                             |
| **End-to-end (E2E) test**               | A test that drives the real app through a real browser, like a person would (Playwright).                                                                                     | Selenium / Playwright for Python                                              |
| **Envelope (sound)**                    | How a sound's volume changes over time: a quick rise (attack) and a fade. It's what makes a tone sound like a pluck or a chime.                                               | a gain curve applied with NumPy                                               |
| **Escrow (reservation)**                | Holding something aside (cards, money) until a deal completes, so it can't be used meanwhile. This app re-checks at acceptance instead.                                       | a pending hold on a bank account                                              |
| **Expected value**                      | The long-run average of a random quantity, such as mythics per pack. Expected values add up across slots.                                                                     | `np.mean` of infinitely many samples                                          |
| **Factory function**                    | A function whose job is to build and return something else, here usually another function with its dependencies already supplied. Named `make…`.                              | a function that returns an inner function (closure), or a class's `__init__`  |
| **Fail-safe**                           | Built so that when a part fails, the whole keeps working in a reduced but sensible way (a missing photo shows generated art; a broken page never fails the sync).             | `try`/`except` per item, logging and continuing                               |
| **Fake**                                | A simple stand-in used in tests, like `fixedClock` or `inMemoryUnitOfWork`.                                                                                                   | a hand-written test double                                                    |
| **Fake timers**                         | A test tool that replaces `setTimeout` with a clock the test moves by hand, so "after 3 seconds" takes no time.                                                               | `freezegun`, or patching `asyncio.sleep`                                      |
| **Fan Content Policy**                  | Wizards of the Coast's rules for free, unofficial projects that use its games' art and text: allowed if free and with a notice, but no logos or trademarks on their own.      | —                                                                             |
| **Fixture**                             | Saved sample data that tests use instead of the real service. Ours are trimmed copies of real MTGJSON and Scryfall data.                                                      | a pytest fixture file / recorded response                                     |
| **Flattened data (`devalue`)**          | JSON stored as one array where numbers point to other slots, so shared objects are stored once and cycles are possible. Rebuilt by following the references.                  | `pickle`'s memo, or JSON with `$ref`s                                         |
| **Function type**                       | A type describing a function's parameters and result, e.g. `(rng: Rng, count: number) => string[]`.                                                                           | `Callable[[Rng, int], list[str]]`                                             |
| **Gateway**                             | The adapter that talks to one outside service (here, MTGJSON or Scryfall) and hands back our own types.                                                                       | an API client class                                                           |
| **Generic / type parameter**            | A placeholder type (`T`) filled in when the type or function is used: `Result<T, E>`, `ok<T>(value: T)`.                                                                      | `TypeVar` / `def f[T](x: T)`                                                  |
| **gzip**                                | A common compression format. `.json.gz` is a gzipped JSON file; Node's `zlib` can unzip it while reading.                                                                     | `gzip.open(...)`                                                              |
| **Hydration**                           | The browser taking over HTML that the server already rendered. The first browser render must match the server's, or React warns.                                              | —                                                                             |
| **Idempotent**                          | Safe to repeat: doing it twice has the same effect as doing it once. `refreshWallet` is idempotent.                                                                           | e.g. `dict[k] = v`, unlike `list.append(v)`                                   |
| **Indexed access type**                 | Getting a type by indexing another type: `(typeof LIST)[number]` is the union of a constant list's elements.                                                                  | `Literal[...]` built from a tuple with `get_args`                             |
| **Integration test**                    | A test that runs against real infrastructure, such as the test database.                                                                                                      | a pytest test using a real DB fixture                                         |
| **Interface**                           | A named description of an object's shape: which properties and methods it has.                                                                                                | `typing.Protocol`                                                             |
| **Intersection (`&`)**                  | A type that is both of two types at once: `number & { … }`.                                                                                                                   | no direct equivalent                                                          |
| **IntersectionObserver**                | A browser feature that calls you back when an element scrolls into (or near) view. Used for infinite scroll.                                                                  | —                                                                             |
| **Job queue**                           | A list of work waiting to be done, processed by a worker. Ours is a database table (`sync_runs`).                                                                             | Celery / RQ, but much smaller                                                 |
| **JSON Lines (`.jsonl`)**               | A file with one JSON object per line, so it can be read line by line instead of all at once.                                                                                  | reading a file with `for line in f: json.loads(line)`                         |
| **Lateral join**                        | A join whose right side is a small query run per row, able to use that row's columns ("for this entry, its best printing").                                                   | a per-row `apply` returning several columns                                   |
| **Lazy (work)**                         | Doing work when it's first needed, instead of on a schedule. Allowances are paid when a wallet is next viewed.                                                                | a `@property` computed on access, or a generator                              |
| **Lazy quantifier (`+?`, `*?`)**        | In a regular expression, matches as little as possible instead of as much as possible, so optional parts after it can still match.                                            | the same syntax in Python's `re`                                              |
| **Ledger**                              | A list of every money change. The balance is their sum. Like a bank statement.                                                                                                | —                                                                             |
| **Linear scale**                        | A function that maps one range of numbers onto another (days to x pixels, prices to y pixels).                                                                                | matplotlib's data-to-display transform                                        |
| **Lint / linter**                       | A tool that checks code for mistakes and rule violations without running it (ESLint).                                                                                         | ruff / flake8                                                                 |
| **Literal type**                        | A type whose only value is one exact value, like `"Cents"` or `true`.                                                                                                         | `Literal["Cents"]`                                                            |
| **Lock order**                          | One fixed order (here: sorted user ids) in which every transaction takes its locks, so waiting can never form a cycle.                                                        | acquiring several `Lock`s in a fixed order                                    |
| **Module** (this project)               | One feature area under `src/modules/<name>/`, such as `wallet` or `catalog`, with its own layers and a public `index.ts`.                                                     | a Python package with a curated `__init__.py`                                 |
| **Monte Carlo simulation**              | Estimating a number by running a random process many times and averaging, such as opening 1,000 packs to measure the mythic rate.                                             | a simulation loop in NumPy                                                    |
| **Mutation testing**                    | Breaking the code on purpose to check that some test fails. A bug no test catches points to a missing test.                                                                   | `mutmut` does it automatically                                                |
| **Narrowing**                           | The compiler working out a more precise type after a check: after `if (x === null) return;`, `x` is no longer `null`.                                                         | mypy's type narrowing after `if x is None`                                    |
| **Negative zero (`-0`)**                | A second zero JavaScript numbers can have. `-0 === 0`, but it prints with a minus sign; `value + 0` turns it into `0`.                                                        | `-0.0` for floats (Python ints have none)                                     |
| **Normalization (of text)**             | Steps that remove differences that don't matter (case, accents, punctuation, plurals) so two names can be compared. Order matters: Unicode normalization turns `™` into `TM`. | `unicodedata.normalize("NFKD", s).lower()`                                    |
| **Nullish coalescing (`??`)**           | `a ?? b` is `a` unless `a` is `null` or `undefined`, then `b`. Unlike `\|\|`, it keeps `0` and `""`.                                                                          | `a if a is not None else b`                                                   |
| **Optimistic update**                   | Changing the screen as if an action succeeded before the server answers, then replacing the guess with the server's answer.                                                   | —                                                                             |
| **Orchestration module**                | A module with no tables of its own that asks other modules to do their parts, in one transaction (the `reset` module).                                                        | a service function calling several repositories inside `transaction.atomic()` |
| **Overload**                            | Several call signatures declared for one function, each with its own precise types.                                                                                           | `@typing.overload`                                                            |
| **Parser**                              | A function that turns text into a structure the program can use, such as a syntax tree.                                                                                       | `ast.parse`, `json.loads`                                                     |
| **Password hash**                       | A one-way scramble of a password (scrypt here). You can check a password against it, but you can't get the password back.                                                     | `bcrypt.hashpw` / Django's password hashers                                   |
| **Point (typography)**                  | The unit PDF measures in: 72 points to the inch. A Magic card is 180 × 252 points.                                                                                            | —                                                                             |
| **Port**                                | An interface describing something the code needs from outside (`Clock`, `UnitOfWork`), without saying how it's provided.                                                      | a `Protocol` used as a parameter type                                         |
| **Precedence (of operators)**           | Which operator groups first: `a b or c` means "(a and b) or c" because `and` binds tighter than `or`.                                                                         | `and` binds tighter than `or` in Python too                                   |
| **Precedence (of values)**              | Which of several possible values wins: "an admin's price, else the official MSRP, else the kind's price". `??` in TypeScript, `coalesce` in SQL.                              | `next(v for v in (a, b, c) if v is not None)`                                 |
| **Precision and recall**                | Two ways a matcher can be wrong. Precision: of the matches it made, how many are right. Recall: of the matches it should make, how many it found.                             | `sklearn.metrics.precision_score` / `recall_score`                            |
| **Promise**                             | A value that will be available later. `Promise<Date>` becomes a `Date` when awaited.                                                                                          | `Awaitable[datetime]` / a coroutine                                           |
| **Property-based test**                 | A test that states a rule ("add then subtract gives back the original") and checks it against many generated inputs.                                                          | Hypothesis                                                                    |
| **Proxy (`proxy.ts`)**                  | Next.js code that runs before every matching request. It's Next 16's new name for "middleware". We use it to bounce signed-out visitors.                                      | Django middleware                                                             |
| **Pseudo-random numbers / seed**        | Numbers from a formula that look random. The starting value, the seed, decides the whole sequence, so the same seed always repeats it.                                        | `random.Random(42)`, `np.random.default_rng(42)`                              |
| **Queue (breadth-first)**               | A list of work waiting to be done: take from the front, add new work to the back. Processes a tree level by level.                                                            | `collections.deque` with `popleft()` and `append()`                           |
| **Race condition**                      | A bug where the result depends on the timing of two things happening at once, e.g. "check, then act" when another request acts in between.                                    | the same concept                                                              |
| **Recursive CTE**                       | A `WITH RECURSIVE` query: a starting set, plus a step applied again and again to what the last step found, until nothing new appears. Walks trees and graphs in SQL.          | a BFS loop over a DataFrame                                                   |
| **Recursive descent**                   | A way to write a parser: one function per rule, calling each other (and themselves, for nesting). Precedence comes from which function calls which.                           | a hand-written parser with `parse_or()` calling `parse_and()`                 |
| **Recursive type**                      | A type that refers to itself, like a product's contents that can contain more contents. Checked with `z.lazy` in Zod.                                                         | a Pydantic model referring to itself as `"Model"`                             |
| **Reduced motion**                      | A system setting for people who get unwell from on-screen movement. Pages check it with `prefers-reduced-motion`.                                                             | —                                                                             |
| **Reducer**                             | A pure function `(state, event) → new state`. Every change to the state goes through it, so it can be tested alone. React runs one with `useReducer`.                         | `functools.reduce(reducer, events, initial)`                                  |
| **Rejection sampling**                  | Enforcing a rule on a random draw by throwing away draws that break it and drawing again. The draws kept keep their relative odds.                                            | a `while not ok(x): x = draw()` loop                                          |
| **Result**                              | This project's return type for operations that can fail normally: either `{ ok: true, value }` or `{ ok: false, error }`.                                                     | returning a tagged union instead of raising                                   |
| **Round-trip test**                     | Writing something out and reading it back, checking nothing changed. Keeps a writer and a reader in step.                                                                     | `json.loads(json.dumps(x)) == x`                                              |
| **Row lock (`SELECT … FOR UPDATE`)**    | Locks the selected rows until the transaction ends, so others wanting the same rows wait.                                                                                     | `with lock:` for one database row                                             |
| **Sampling with / without replacement** | Drawing several items either independently (the same item can repeat) or like dealing cards (each item at most once).                                                         | `random.choices` / `random.sample`, `replace=` in NumPy                       |
| **Server Action**                       | A server function a form can call directly. Its file starts with `"use server"`. Our controllers are server actions.                                                          | a Flask/Django view that handles a POST                                       |
| **Server Component**                    | A React component that runs only on the server and sends finished HTML. It's the default in Next.js, and it can read the database directly.                                   | a Django template view                                                        |
| **Service**                             | An object (usually from a factory) that groups related operations, such as the wallet's `balance` and `debit`.                                                                | a class with a few related methods                                            |
| **Session**                             | "This browser is signed in as player X": a random token (in a cookie) that the server looks up on each request.                                                               | `request.session` in Django/Flask                                             |
| **Signal (SIGINT, SIGTERM)**            | A message the operating system sends a process: SIGINT is Ctrl+C, SIGTERM is "please stop" (what Docker sends).                                                               | `signal.signal(signal.SIGTERM, handler)`                                      |
| **Soft delete (unlisting)**             | Marking a row inactive instead of deleting it, so data that points to it keeps working.                                                                                       | an `is_active` column                                                         |
| **Spread (`...`)**                      | Unpacks a list into separate values (`push(...items)`) or copies an object's fields into a new one (`{ ...item, status: "opened" }`).                                         | `*items` and `{**item, "status": "opened"}`                                   |
| **SQL injection**                       | An attack where text typed by a user is pasted into SQL and runs as code. Prevented by sending values as parameters.                                                          | why you never build SQL with f-strings                                        |
| **Stale response**                      | An answer to an older request that arrives after a newer one was sent. It must be ignored or it overwrites newer results.                                                     | a superseded `asyncio` task's result                                          |
| **Standard error**                      | How much a measured rate typically wobbles between runs: √(p × (1 − p) ÷ n) for a rate p over n tries.                                                                        | `scipy.stats.sem`                                                             |
| **State machine**                       | A fixed set of states and the moves allowed between them (an item goes from unopened to opened, never back).                                                                  | an `Enum` plus a transition function                                          |
| **Strategy (pattern)**                  | Interchangeable functions with the same shape, chosen at runtime (here from a lookup table).                                                                                  | a dict mapping names to functions                                             |
| **Stream**                              | Data processed piece by piece as it arrives, instead of loading it all into memory.                                                                                           | iterating a file or a generator                                               |
| **Structural typing**                   | Types match by **shape**: anything with the right properties fits, whatever it's called or where it came from.                                                                | how `Protocol` works                                                          |
| **SVG**                                 | A picture described as text: shapes like `<polyline>` and `<circle>` with coordinates, which the browser draws at any size.                                                   | a matplotlib figure saved as `.svg`                                           |
| **Syntax tree**                         | Text parsed into nested nodes ("and", "or", "not", one condition) that code can walk.                                                                                         | the tree `ast.parse` returns                                                  |
| **Token**                               | One of the smallest meaningful pieces of text a parser works with: a word, `or`, a parenthesis.                                                                               | what `shlex.split` returns                                                    |
| **Transaction**                         | A group of database changes that succeed or fail together.                                                                                                                    | `with conn:` in most DB libraries                                             |
| **Transactional outbox**                | Writing an event in the same transaction as the change it describes, so they succeed or fail together.                                                                        | inserting an audit row in the same `session` before `commit()`                |
| **Type alias (`type X = …`)**           | A name for a type. It describes a shape, creates nothing at runtime, and is erased when compiled.                                                                             | `TypedDict`, or `X = int \| str`                                              |
| **Type-only import (`import type`)**    | An import used only by the compiler and erased from the running code, so no code from the other module is loaded.                                                             | imports under `if TYPE_CHECKING:`                                             |
| **Typed confirmation**                  | Asking someone to type a word (START OVER, a username) before an action that can't be undone, so a stray click can't trigger it.                                              | —                                                                             |
| **Unit of work**                        | This project's wrapper around a transaction: run some work, commit if it returns `ok`, roll back if it returns `err` or throws.                                               | a context manager around a transaction                                        |
| **Untrusted input**                     | Data from outside (another site, a user) that may change shape or contain things you shouldn't show. Validate it, allow-list it, and show it as text.                         | sanitizing with `bleach`                                                      |
| **Upsert**                              | Insert a row, or update it if one with the same key already exists: `INSERT … ON CONFLICT DO UPDATE`.                                                                         | `dict.update` / `INSERT OR REPLACE`                                           |
| **Use case**                            | One action the app can perform for a user, such as "check health", "buy a booster" or "open a pack". Each is a function built by a factory.                                   | a service-layer function                                                      |
| **Walking skeleton**                    | The thinnest possible feature that goes through every layer end to end, built early to prove the wiring works. Here: the health check.                                        | —                                                                             |
| **Web Audio API**                       | The browser's toolkit for making sound from connected nodes: sources, filters and volume, playing through the speakers.                                                       | `scipy.signal` plus a sound card, live                                        |
| **Weighted sampling**                   | Picking items with probability proportional to their weight: weight 3 is three times as likely as weight 1.                                                                   | `random.choices(items, weights=w)`                                            |
| **Word boundary**                       | A regular-expression marker for the edge of a word: `\b` in JavaScript, `\m`/`\M` in Postgres. `\bcase\b` matches "Case" but not "Showcase".                                  | `\b` in `re`                                                                  |
| **Worker pool**                         | A fixed number of workers taking jobs from a shared queue until it's empty, so at most that many run at once.                                                                 | `asyncio.Semaphore`, or `ThreadPoolExecutor(max_workers=6)`                   |
